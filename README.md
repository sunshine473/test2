# Claude Skills & Agents Development Workspace

This repository is a formal workspace for designing, developing, and testing Claude Skills and Agents.

## Structure

- **`src/`**: Implementation code for Skills and Agents.
- **`tests/`**: Automated tests and validation scripts.
- **`assets/`**: Static resources.
- **`docs/`**: Requirements and planning documentation.
- **`参考/`**: Reference materials and guides (e.g., "How to create Skills for Claude").

## Getting Started

1.  Review **[AGENTS.md](AGENTS.md)** for contributor guidelines and conventions.
2.  Check `docs/需求说明.md` for current goals.
3.  Use the `src/` directory for your implementation.

## Development Workflow

1.  **Plan**: Define requirements in `docs/`.
2.  **Develop**: Implement skills in `src/`.
3.  **Verify**: Add tests in `tests/`.
