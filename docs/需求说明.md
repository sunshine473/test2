# 需求说明

## 1. 背景

运营科技/AI + 汽车/出行领域的公众号，需要持续产出高质量内容。手动采集素材、写作、发布的流程耗时且难以规模化。

## 2. 目标

构建一个半自动化的内容工厂，覆盖从素材采集到多平台分发的完整链路：
- 自动采集并筛选高价值素材
- LLM 辅助生成文章草稿
- 人工审核后一键多平台发布

## 3. 内容领域与采集渠道

### 3.1 采集方式分层

| 采集方式 | 适用场景 | 优势 |
|----------|----------|------|
| 直接抓取 | 有稳定页面结构的站点 | 数据精确、可控 |
| RSS 订阅 | 有 feed 输出的站点（含 YouTube 频道） | 稳定、轻量 |
| Tavily 搜索 | 无 API/RSS 的站点、热点追踪 | 覆盖广、不用写爬虫 |
| X/Twitter | KOL 和官方账号动态 | 一手信息、时效性强 |

## 4. 核心 SOP

```
素材采集（自动）→ 选题推荐（自动）→ 人工选题 → 内容生成（自动）→ 人工审核 → 发布分发（一键）
```

### 4.1 素材采集层
- 按领域配置信息源，定时或手动触发采集
- 素材去重 + 聚类（相似话题合并）
- LLM 打分（热度 × 相关性 × 写作价值），生成每日选题清单

### 4.2 内容生成层
- 用户从选题清单中挑选 1-3 个，可附加写作角度
- LLM 基于选题 + 原始素材生成 Markdown 长文草稿
- 草稿落入 `content/drafts/`，人工审核修改后移入 `content/ready/`

### 4.3 发布分发层
- `wechat_publisher` 推送到微信公众号草稿箱
- `MultiPost` 浏览器扩展同步到懂车帝、知乎、B站、头条等 30+ 平台
- 发布后归档到 `content/published/`

## 5. 自动化程度

半自动模式，两个人工卡点：
- ★ 选题确认：AI 推荐，人拍板
- ★ 草稿审核：AI 生成，人把关

## 6. 技术选型

- 脚本层：Python（采集、处理、发布）
- 调度层：Claude Skills（交互入口）+ 脚本（实际执行）
- LLM：Claude API / OpenAI API / 国内模型（按需切换）
- 多平台分发：MultiPost 浏览器扩展（Plasmo + TypeScript）

## 7. 目录结构（目标）

```
src/
├── collector/           # 素材采集
│   ├── sources/         # 各信息源适配器
│   │   ├── github_trending.py   # 直接抓取
│   │   ├── rss.py               # RSS 订阅（HN、OpenAI、Anthropic、DeepMind、36kr、YouTube 频道）
│   │   ├── twitter.py           # X/Twitter 账号采集
│   │   └── tavily_search.py     # Tavily 搜索（懂车帝、汽车之家、热搜等）
│   ├── dedup.py         # 去重 + 聚类
│   └── scorer.py        # LLM 打分排序
├── generator/           # 内容生成
│   ├── writer.py        # LLM 写作
│   └── templates/       # 文章模板
├── publisher/           # 发布（已有 wechat_publisher，迁移优化）
├── pipeline/            # 流水线调度
│   └── main.py
└── config/              # 统一配置
    ├── sources.yaml     # 信息源配置（URL、query、采集方式）
    └── prompts/         # 各环节 prompt 模板

skills/
├── collect/             # /collect — 触发采集 + 展示选题
├── write/               # /write — 生成文章草稿
└── publish/             # /publish — 一键发布

content/                 # 内容仓库
├── drafts/              # 草稿
├── ready/               # 待发布
└── published/           # 已发布归档
```

## 8. 验收标准

- [ ] `/collect` 能采集至少 3 个信息源，输出打分排序的选题清单
- [ ] `/write` 能基于选题生成 2000 字以上的 Markdown 文章
- [ ] `/publish` 能将文章推送到微信公众号草稿箱
- [ ] MultiPost 能成功同步到懂车帝
- [ ] 内容生命周期（drafts → ready → published）可追踪
