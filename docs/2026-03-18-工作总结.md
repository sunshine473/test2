## 🔧 技术细节

### AI 选题评估流程
1. 从 `recommended_topics` 获取 AI 推荐的选题列表
2. 调用 Claude Opus 4.6 进行 5 维度评估
3. 分析每个选题的时效性、热度、深度、差异化、价值
4. 自动选择评分最高的选题
5. 输出选择理由和评分

### AI 质量审核流程
1. 读取生成的文章内容
2. 调用 Gemini API 进行 6 维度评分
3. 评估标题、开头、结构、逻辑、可读性、信息密度
4. 计算总分（满分 100）
5. 判断是否通过（≥70 分）
6. 不通过则自动重写（最多 3 次）

### 数据流
```
素材采集 → content/pool/2026-03-18-pool.json
         → Notion 素材池数据库

选题策划 → state.recommended_topics
         → Notion 选题库数据库

AI 选题 → state.selected_topic
        → state.selected_sources

内容生成 → content/drafts/2026-03-18-AI开发告别玄学....md
         → Notion 草稿库数据库

质量审核 → state.review_score (90/100)
         → state.review_passed (true)
         → state.review_feedback
```

## 💡 经验总结

### 成功经验
1. **渐进式验证**：先验证单个模块，再验证完整流程
2. **类型提示规范**：统一使用 `Optional[type]` 确保 Python 3.9 兼容性
3. **AI 协作**：Claude 选题 + Gemini 生成 + Gemini 审核，各司其职
4. **文档先行**：及时更新文档，确保信息同步

### 遇到的问题
1. **网络问题**：部分采集源失败（HN, GitHub, Tavily）
   - 解决方案：RSS 源作为备用，确保基本素材供应
2. **类型提示兼容性**：Python 3.9 不支持 PEP 604 语法
   - 解决方案：批量替换为 `Optional[type]`
3. **流水线超时**：长时间运行导致进程被终止
   - 解决方案：分阶段执行，保存中间状态

### 改进方向
1. **网络重试**：添加更智能的重试机制
2. **错误处理**：完善异常捕获和错误恢复
3. **性能监控**：添加各阶段耗时统计
