# 批量内容生产功能实现总结

## 实现内容

### 1. 批量生产流水线
**文件**: `src/pipeline/batch_pipeline.py`

**核心功能**:
- `BatchPipeline` 类 - 批量内容生产流水线
- 自动生成多篇文章（每个方向 N 篇）
- 发布到指定平台（小红书、知乎等）
- 生成汇总报告

**工作流程**:
```
阶段 1: 素材搜索（1 次）
阶段 2: 选题策划（2 个方向）
阶段 3: 批量生成（每方向 N 篇）
阶段 4: 汇总报告
```

### 2. Batch Factory Skill
**文件**: `.claude/skills/batch-factory/SKILL.md`

**核心特性**:
- 默认配置：每个方向 2 篇，发布到小红书和知乎
- 支持自定义数量和平台
- 详细的使用说明和输出示例

## 默认配置

**生成数量**:
- AI 科技方向：2 篇
- 汽车方向：2 篇
- 总计：4 篇文章

**发布平台**:
- 小红书：4 篇（2 篇 AI + 2 篇汽车）
- 知乎：4 篇（2 篇 AI + 2 篇汽车）
- 总计：8 次发布

## 执行流程详解

### 阶段 1: 素材搜索（只执行 1 次）
```
采集多源素材 → 去重聚类 → 输出素材池
```

**优势**: 批量模式下，素材搜索只执行一次，节省时间

### 阶段 2: 选题策划（2 个方向）
```
AI 科技方向: 筛选 → 打分 → AI 推荐 3-5 个选题
汽车方向:   筛选 → 打分 → AI 推荐 3-5 个选题
```

**优势**: 选题策划只执行一次，为后续批量生成提供选题池

### 阶段 3: 批量生成（每方向 N 篇）
对每个选题：
```
1. 生成文章内容
2. 生成视觉卡片（可选）
3. AI 质量审核（6 维度评分）
4. 审核不通过自动重写
5. 发布到指定平台
```

**示例**（默认配置）:
```
AI 科技方向:
  [1/2] GPT-5 来了：AI 大模型进入新纪元
    → 生成 → 审核(85分) → 发布(小红书+知乎)
  [2/2] Claude 3.5 发布：多模态能力全面升级
    → 生成 → 审核(82分) → 发布(小红书+知乎)

汽车方向:
  [1/2] 特斯拉 FSD V12 体验：完全自动驾驶真的来了？
    → 生成 → 审核(88分) → 发布(小红书+知乎)
  [2/2] 比亚迪秦 PLUS DM-i 深度评测
    → 生成 → 审核(80分) → 发布(小红书+知乎)
```

### 阶段 4: 汇总报告
```
============================================================

============================================================

  AI 科技方向: 2 篇
  汽车方向: 2 篇

    2. [AI 科技] Claude 3.5 发布：多模态能力全面升级 - ✅ 82/100
    3. [汽车] 特斯拉 FSD V12 体验：完全自动驾驶真的来了？ - ✅ 88/100
    4. [汽车] 比亚迪秦 PLUS DM-i 深度评测 - ✅ 80/100

============================================================
```

## 性能估算

假设每篇文章生成 + 审核 + 发布需要 5 分钟：

| 配置 | 文章数 | 发布次数 | 预计时间 |
|------|--------|---------|---------|
| 默认（2 篇/方向） | 4 篇 | 8 次 | ~20 分钟 |
| 3 篇/方向 | 6 篇 | 12 次 | ~30 分钟 |
| 4 篇/方向 | 8 篇 | 16 次 | ~40 分钟 |
| 5 篇/方向 | 10 篇 | 20 次 | ~50 分钟 |

**建议**: 首次使用建议 `--count 1` 测试流程

## 与单篇模式对比

| 特性 | 单篇模式 (/factory) | 批量模式 (/batch-factory) |
|------|-------------------|------------------------|
| 素材搜索 | 每次执行 | 只执行一次 ✅ |
| 选题策划 | 每次执行 | 只执行一次 ✅ |
| 生成数量 | 1 篇 | N 篇 × 2 方向 |
| 发布平台 | 可指定 | 可指定 |
| 执行时间 | 快（~5 分钟） | 慢（N × 5 分钟） |
| 适用场景 | 单篇文章 | 批量生产 |
| 效率提升 | - | 节省素材搜索和选题时间 |

## 优势

### 1. 效率提升
- 素材搜索只执行一次（节省 ~3 分钟）
- 选题策划只执行一次（节省 ~2 分钟）
- 批量生成，无需人工干预

### 2. 质量保证
- 每篇文章都经过 AI 质量审核
- 审核不通过自动重写
- 确保所有文章达到 70 分以上

### 3. 多平台覆盖
- 一次生成，多平台发布
- 支持小红书、知乎、B站等
- 自动记录发布结果

### 4. 可追溯性
- 每篇文章有独立的流水线状态
- 批量结果 JSON 记录所有信息
- 便于后续分析和优化

## 常见问题

**Q: 如何只生成不发布？**
A: 暂不支持，可以在 `publishers.yaml` 中禁用所有平台

**Q: 如何指定只生成某个方向？**
A: 暂不支持，批量模式会生成两个方向

**Q: 审核不通过会怎样？**
A: 自动重写，最多重试 3 次

**Q: 发布失败会怎样？**
A: 记录失败原因，继续处理下一篇

**Q: 如何查看详细日志？**
A: 每篇文章的流水线状态保存在 `content/pipeline/<pipeline_id>.json`

**Q: 如何恢复中断的批量任务？**
A: 暂不支持恢复，需要重新执行

## 后续优化

### 1. 并行生成
- 当前是串行生成（一篇接一篇）
- 可以改为并行生成（同时生成多篇）
- 预计可提升 2-3 倍效率

### 2. 断点续传
- 支持从中断点恢复
- 避免重复生成已完成的文章

### 3. 智能调度
- 根据平台限流自动调整发布速度
- 避免触发反爬机制

### 4. 质量分析
- 统计各方向文章的平均评分
- 分析哪些选题更受欢迎
- 优化选题策略
