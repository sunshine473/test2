# 六层架构映射说明 / Six-Layer Architecture Mapping

## 目的 / Purpose

本文将“内容 Skills 六层递进架构”映射到当前仓库，说明哪些层已经具备，哪些层仍然耦合，以及建议的演进方向。

This document maps the “six-layer content skills architecture” to the current repository, showing which layers already exist, which remain coupled, and how the system should evolve.

## 参考架构 / Reference Architecture

六层参考架构可概括为：

The six-layer reference architecture can be summarized as:

1. 采集层 / Collect
2. 整理或翻译层 / Normalize or Translate
3. 创作层 / Create
4. 排版与包装层 / Package
5. 多媒体扩展层 / Multimedia
6. 分发与同步层 / Distribute and Sync

## 建议的演进顺序 / Recommended Evolution Order

1. 先补文档契约：明确 `RawMaterial`、`MaterialPool`、`TopicPlan`、`DraftPackage`、`PublishPackage`。
2. 再拆整理层：把清洗、翻译、去重、正文补齐从 `collector` 中抽出。
3. 再补包装层：把平台格式化前移为独立步骤。
4. 最后再扩多媒体层：进入视频脚本、语音、短视频封装。

1. First complete the contract docs: define `RawMaterial`, `MaterialPool`, `TopicPlan`, `DraftPackage`, and `PublishPackage`.
2. Then split the normalize layer: extract cleaning, translation, deduplication, and content enrichment from `collector`.
3. Then add the packaging layer: move platform-specific formatting into an explicit pre-publish step.
4. Only then extend the multimedia layer: add video scripts, voice, and short-form packaging.

```python
from typing import List
from src.models.raw_material import RawMaterial
from src.models.material_pool import MaterialPool
from .cleaner import clean_materials
from .dedup import deduplicate
from .translator import translate_materials

def normalize(raw_materials: List[RawMaterial]) -> MaterialPool:
    “””整理原始素材，输出标准化素材池”””
    # 1. 清洗文本
    cleaned = clean_materials(raw_materials)

    # 2. 去重聚类
    deduplicated = deduplicate(cleaned)

    # 3. 翻译（可选）
    translated = translate_materials(deduplicated)

    return MaterialPool(
        materials=translated,
        created_at=datetime.now(),
        total_count=len(translated),
        duplicate_count=len(raw_materials) - len(deduplicated),
        cluster_count=len(set(m.cluster_id for m in translated if m.cluster_id))
    )
```

```python
from src.models.draft_package import DraftPackage
from src.models.publish_package import PublishPackage, PlatformPayload
from .common import markdown_to_html, upload_images_to_wechat

def package_for_wechat(draft: DraftPackage) -> PlatformPayload:
    “””将草稿包装为微信发布格式”””
    # 1. Markdown → 微信 HTML
    html = markdown_to_html(
        draft.content_markdown,
        style=”wechat”,
        theme=”default”
    )

    # 2. 上传封面图
    cover_media_id = None
    if draft.cover_image:
        cover_media_id = upload_images_to_wechat([draft.cover_image])[0]

    # 3. 上传文中图片
    image_urls = extract_images_from_markdown(draft.content_markdown)
    uploaded_images = upload_images_to_wechat(image_urls)

    # 4. 替换图片链接
    html = replace_image_urls(html, dict(zip(image_urls, uploaded_images)))

    return PlatformPayload(
        platform=”wechat”,
        title=draft.title,
        content=html,
        format=”html”,
        cover_image=cover_media_id,
        images=uploaded_images,
        extra_fields={
            “need_open_comment”: 1,
            “only_fans_can_comment”: 0
        },
        estimated_size=len(html.encode('utf-8')),
        validation_passed=True
    )
```

```python
from src.models.material_pool import MaterialPool
from src.models.topic_candidate import TopicCandidate

def plan_topics(pool: MaterialPool, direction: str) -> List[TopicCandidate]:
    “””从素材池生成选题候选”””
    # 1. 按方向筛选
    filtered = filter_by_direction(pool.materials, direction)

    # 2. 评分排序
    scored = score_materials(filtered)

    # 3. AI 推荐选题
    candidates = recommend_topics(scored, direction)

    return candidates

def recommend_topics(materials: List[NormalizedMaterial], direction: str) -> List[TopicCandidate]:
    “””AI 推荐选题”””
    # 聚类相似素材
    clusters = cluster_materials(materials)

    candidates = []
    for cluster in clusters[:5]:  # 推荐 Top 5
        # 生成选题
        topic = generate_topic_from_cluster(cluster, direction)
        candidates.append(TopicCandidate(
            id=generate_uuid(),
            title=topic[“title”],
            direction=direction,
            source_materials=[m.id for m in cluster],
            primary_material_id=cluster[0].id,
            angle=topic[“angle”],
            target_audience=topic[“audience”],
            estimated_length=topic[“length”],
            content_type=topic[“type”],
            relevance_score=topic[“scores”][“relevance”],
            timeliness_score=topic[“scores”][“timeliness”],
            depth_score=topic[“scores”][“depth”],
            engagement_score=topic[“scores”][“engagement”],
            overall_score=topic[“scores”][“overall”],
            reason=topic[“reason”],
            key_points=topic[“key_points”],
            status=”pending”,
            planner_version=”1.0.0”
        ))

    return candidates
```
