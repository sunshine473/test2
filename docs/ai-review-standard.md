# AI 质量审核标准

## 概述

从 M3 版本开始，流水线的 review 阶段由 AI 自动审核，替代人工审核。使用 Gemini 2.0 Flash 模型对文章进行 6 维度评分，总分 >= 70 分通过，< 70 分自动打回重写。

## 评分维度

### 1. 标题吸引力 (0-20分)

**评分标准**：
- 是否有悬念、冲突、反常识？
- 是否包含数字、具体场景？
- 是否简洁有力（15字以内）？
- 是否避免标题党（夸大、误导）？

**优秀示例**：
- ✅ "GPT-5 发布：3 个颠覆性功能，OpenAI 这次玩真的"
- ✅ "特斯拉 FSD 12.0 实测：城市道路零接管，但有个致命问题"
- ❌ "关于 AI 的一些思考"（太泛）
- ❌ "震惊！AI 竟然能做到这个！"（标题党）

### 2. 开头钩子 (0-15分)

**评分标准**：
- 前 3 句是否抓住读者注意力？
- 是否用故事、数据、问题开场？
- 是否快速切入主题（不啰嗦）？

**优秀示例**：
- ✅ "上周，OpenAI 悄悄发布了 GPT-5。没有发布会，没有预热，甚至连官方博客都没更新。但这次更新，可能改变整个 AI 行业的游戏规则。"
- ✅ "你有没有想过，为什么特斯拉的自动驾驶总是在最后一刻刹车？"
- ❌ "随着人工智能技术的不断发展，越来越多的应用场景被开发出来..."（套话）

### 3. 内容结构 (0-20分)

**评分标准**：
- 是否有清晰的逻辑框架（总分总、递进、对比）？
- 段落是否短小精悍（3-5 行）？
- 是否有小标题、列表、引用等排版元素？
- 是否有节奏感（快慢结合）？

**优秀示例**：
```markdown
## 核心功能

### 1. 多模态理解

GPT-5 可以同时处理文本、图像、音频...

### 2. 长上下文

支持 100 万 token 上下文...

### 3. 推理能力

在数学、编程等任务上...
```

### 4. 逻辑连贯性 (0-15分)

**评分标准**：
- 论点是否清晰？
- 论据是否充分？
- 段落之间是否有过渡？
- 是否有逻辑跳跃或自相矛盾？

**常见问题**：
- ❌ 前面说"A 是最好的"，后面又说"B 更优秀"
- ❌ 段落之间缺乏过渡，读起来像拼凑
- ❌ 结论与论据不匹配

### 5. 可读性 (0-15分)

**评分标准**：
- 语言是否简洁流畅？
- 是否避免专业术语堆砌？
- 是否有具体案例、比喻？
- 是否有情感共鸣？

**优秀示例**：
- ✅ "GPT-5 的推理能力，就像从小学生升级到大学生"（比喻）
- ✅ "我测试了 100 次，只有 3 次失败"（具体数据）
- ❌ "该模型采用了 Transformer 架构，通过 Self-Attention 机制..."（术语堆砌）

### 6. 信息密度 (0-15分)

**评分标准**：
- 是否有新信息、新观点？
- 是否避免废话、套话？
- 是否有数据、引用支撑？
- 是否有实用价值？

**常见问题**：
- ❌ 大段空话："在当今这个快速发展的时代..."
- ❌ 重复啰嗦：同一个观点反复说
- ❌ 缺乏数据支撑：只有观点，没有证据

## 通过标准

- **总分 >= 70 分**：审核通过，进入发布阶段
- **总分 < 70 分**：审核不通过，打回重写

## 使用方式

### 自动模式（推荐）

```bash
# AI 自动审核，不通过自动重写
/factory --auto
```

### 半自动模式

```bash
# 1. 启动流水线
/factory

# 2. 选择选题
/factory --resume latest --topic "选题标题"

# 3. AI 自动审核（如果不通过会暂停）
# 查看审核报告
cat content/pipeline/<timestamp>.json

# 4a. 审核通过，继续发布
/factory --resume latest --approve

# 4b. 审核不通过，重新生成
/factory --resume latest --rewrite

# 4c. 审核不通过，手动修改后继续
# 编辑 content/drafts/<slug>/article.md
/factory --resume latest --approve
```

## 审核报告示例

```json
{
  "review_score": 68,
  "review_passed": false,
  "review_feedback": "# 内容质量评估报告\n\n**总分: 68/100** ❌ 不合格\n\n## 评分详情\n\n### 1. 标题吸引力 (15/20)\n标题包含数字和具体场景，但缺乏悬念感...\n\n### 2. 开头钩子 (10/15)\n开头使用了数据，但前 3 句未能快速切入主题...\n\n..."
}
```
