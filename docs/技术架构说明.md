## 信息源采集方案

### RSS 订阅（含 YouTube）

| 项目 | 说明 |
|------|------|
| 工具 | `feedparser` (Python) |
| 成本 | 免费，无限制 |
| 覆盖 | HN、OpenAI Blog、Anthropic Blog、DeepMind Blog、36kr、7 个 YouTube 频道 |
| 原理 | 标准 RSS/Atom 解析，YouTube 频道通过 `youtube.com/feeds/videos.xml?channel_id=XXX` 获取 |

YouTube 频道的 RSS 返回最新 15 个视频的标题、链接、发布时间。需要视频内容时，用 `youtube-transcript-api` 提取字幕文本，再送入 LLM 摘要。

```
YouTube RSS → 新视频列表 → youtube-transcript-api 提取字幕 → LLM 摘要/打分
```

关键依赖：
- `feedparser` — RSS 解析
- `youtube-transcript-api` — 字幕提取（免费，无需 API Key）

### X/Twitter

| 项目 | 说明 |
|------|------|
| 当前方案 | Tavily 间接搜索（`from:handle` query） |
| 成本 | 复用已有 Tavily API Key |
| 覆盖 | 30 个账号，分 5 类（大佬/研究/聚合/工具/官方） |
| 备选方案 | twikit（4K star）或 twscrape（2.2K star），需账号登录 |

X 官方 API 基础版 $200/月，企业版 $42,000+/年，且自建爬虫每月需 10-15 小时维护（token 过期、GraphQL ID 轮换）。当前阶段用 Tavily 间接搜索最务实，后续数据量不够再考虑升级。

### GitHub Trending

| 项目 | 说明 |
|------|------|
| 工具 | `requests` + `BeautifulSoup` |
| 成本 | 免费 |
| 原理 | HTML 抓取 `github.com/trending?since=daily`，解析 `article.Box-row` 元素 |

### Tavily 搜索

| 项目 | 说明 |
|------|------|
| 工具 | `tavily-python` |
| 成本 | 按 API 用量计费（已有 Key） |
| 覆盖 | 懂车帝、汽车之家、新能源政策、微博/百度/知乎热搜等无 RSS 的站点 |
| 原理 | 关键词搜索，返回标题 + 摘要 + URL |

## 处理管线

### 去重聚类 (dedup.py)

两级去重策略：
1. URL / 标题精确去重 — 过滤完全重复的内容
2. 语义相似度去重 — 用 embedding 向量计算相似度，合并同一话题的不同报道

轻量实现：本地 `sentence-transformers` 生成 embedding，余弦相似度 > 0.85 判定为重复。无需外部向量数据库，SQLite 即可存储。

### LLM 打分 (scorer.py)

对去重后的素材，调用 LLM 按三个维度打分（1-10）：
- 热度：话题当前的关注度
- 相关性：与科技/AI 或汽车/出行领域的匹配度
- 写作价值：是否适合展开为公众号长文

综合分 = 热度 × 0.3 + 相关性 × 0.4 + 写作价值 × 0.3

输出按分数降序排列的选题清单（JSON）。

## 内容仓库 (content/)

```
content/
├── drafts/          # LLM 生成的草稿，待人工审核
│   └── 2026-02-17-标题.md
├── ready/           # 审核通过，待发布
│   └── 2026-02-17-标题.md
└── published/       # 已发布归档
    └── 2026-02-17-标题.md
```

文件命名规范：`YYYY-MM-DD-标题slug.md`，frontmatter 包含元数据：

```yaml
---
title: 文章标题
date: 2026-02-17
category: tech_ai | auto
sources:
  - url: https://...
    title: 原始素材标题
status: draft | ready | published
published_at: null
platforms: []
---
```

## 通知渠道

### Notion 同步 (notion_output.py)

搜索阶段完成后，将去重后的素材逐条写入 Notion 数据库，支持双语标题/摘要。

### Telegram 通知 (telegram_notifier.py)

策划阶段完成后，推送选题摘要到 Telegram，方便手机端快速浏览。

- 使用 Telegram Bot API `sendMessage`，纯 HTTP 调用，无额外依赖
- 未配置 `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` 时静默跳过
- 通知内容：采集统计 + 各方向 Top 5 选题（标题、URL、分数）
