## 状态定义 / Status Definition

| 状态 | 含义 | 标准 |
|------|------|------|
| **production** | 生产可用 | 有完整实现 + 测试覆盖 + 文档 + 已在实际使用 |
| **beta** | 功能完整但需优化 | 核心功能可用 + 有基础测试 + 存在已知问题 |
| **skeleton** | 骨架实现 | 只有接口定义或最小实现 + 未经充分测试 |
| **blocked** | 阻塞中 | 依赖未就绪或存在技术障碍 |
| **planned** | 已规划未开始 | 在开发计划中但未动工 |
