# 内容流水线数据契约 / Content Pipeline Data Contracts

## 目的 / Purpose

本文定义内容流水线各阶段的标准输入与输出，作为模块协作、Agent 协作、测试验收和后续重构的统一契约。

This document defines the standard inputs and outputs for each stage of the content pipeline. It serves as the shared contract for module collaboration, agent collaboration, test validation, and future refactors.

## 设计原则 / Design Principles

- 上一层的输出必须能作为下一层的稳定输入。
- 每层只负责一个核心职责，不混入相邻层的逻辑。
- 字段优先“少而稳定”，避免阶段间协议频繁漂移。
- 中间产物是正式资产，允许落盘、回放、重跑和审计。

- The output of one layer must be a stable input to the next layer.
- Each layer owns one core responsibility and should not absorb neighboring logic.
- Prefer small, stable schemas over wide, fast-changing payloads.
- Intermediate artifacts are first-class assets and should support persistence, replay, reruns, and auditing.

## 契约定义 / Contract Definitions

### 1. `RawMaterial`

#### 用途 / Usage

采集层的标准单条输出，尽量保留原始信息，不做重业务判断。

The standard single-item output of the collect layer. It should preserve source information with minimal business interpretation.

#### 字段 / Fields

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | `string` | 是 | 素材标题 |
| `url` | `string` | 是 | 原始链接 |
| `source_name` | `string` | 是 | 来源名称 |
| `source_type` | `string` | 是 | 采集方式，如 `rss`、`api`、`tavily` |
| `category` | `string` | 是 | 业务分类，如 `tech_ai`、`auto`、`trending` |
| `summary` | `string` | 否 | 短摘要，适合列表展示 |
| `content` | `string` | 否 | 主要内容摘录，适合策划和写作 |
| `published_at` | `string` | 否 | 发布时间，推荐 ISO8601 |
| `language` | `string` | 否 | 原文语言 |
| `raw_data` | `object` | 否 | 来源专属补充字段 |

| Field | Type | Required | Description |
|------|------|------|------|
| `title` | `string` | Yes | Material title |
| `url` | `string` | Yes | Original link |
| `source_name` | `string` | Yes | Source display name |
| `source_type` | `string` | Yes | Collection method, such as `rss`, `api`, or `tavily` |
| `category` | `string` | Yes | Business category such as `tech_ai`, `auto`, or `trending` |
| `summary` | `string` | No | Short summary for list display |
| `content` | `string` | No | Main-content excerpt for planning and writing |
| `published_at` | `string` | No | Publish time, preferably ISO8601 |
| `language` | `string` | No | Original language |
| `raw_data` | `object` | No | Source-specific extra fields |

### 2. `MaterialPool`

#### 用途 / Usage

整理层输出的素材池，作为策划层的唯一标准输入。

The normalized material pool produced by the normalize layer. It is the single standard input for planning.

#### 顶层字段 / Top-Level Fields

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `date` | `string` | 是 | 素材池日期 |
| `stage` | `string` | 是 | 固定为 `search` |
| `raw_total` | `number` | 是 | 原始采集条数 |
| `source_stats` | `object` | 是 | 分源统计 |
| `dedup_total` | `number` | 是 | 去重后条数 |
| `cluster_summary` | `object` | 是 | 聚类统计 |
| `items` | `RawMaterial[]` | 是 | 去重后的素材列表 |

| Field | Type | Required | Description |
|------|------|------|------|
| `date` | `string` | Yes | Pool date |
| `stage` | `string` | Yes | Fixed as `search` |
| `raw_total` | `number` | Yes | Number of raw collected items |
| `source_stats` | `object` | Yes | Per-source statistics |
| `dedup_total` | `number` | Yes | Number of items after deduplication |
| `cluster_summary` | `object` | Yes | Clustering summary |
| `items` | `RawMaterial[]` | Yes | Deduplicated material items |

#### `items[].raw_data` 约定字段 / Reserved `items[].raw_data` Keys

- `cluster_id`
- `cluster_size`
- 来源专属附加字段，如 `video_id`、`channel_id`、`hn_points`

- `cluster_id`
- `cluster_size`
- Source-specific fields such as `video_id`, `channel_id`, or `hn_points`

| `score` | `number` | 是 | 综合评分 |
| `source_items` | `RawMaterial[]` | 是 | 关联素材 |
| `why_now` | `string` | 否 | 时效性说明 |
| `angle` | `string` | 否 | 推荐切入角度 |
| `key_points` | `string[]` | 否 | 建议写作要点 |

| Field | Type | Required | Description |
|------|------|------|------|
| `topic_title` | `string` | Yes | Recommended topic title |
| `direction` | `string` | Yes | Direction such as `tech_ai` or `auto` |

| `angle` | `string` | No | Suggested writing angle |
| `key_points` | `string[]` | No | Suggested key points |

| `format` | `string` | 是 | `markdown` / `html` / `rich_text` |
| `cover_assets` | `string[]` | 否 | 封面资源路径或 URL |
| `extra` | `object` | 否 | 平台专属字段 |

| Field | Type | Required | Description |
|------|------|------|------|
| `title` | `string` | Yes | Title |
| `platform` | `string` | Yes | Target platform |
| `body` | `string` | Yes | Platform-ready body |
| `format` | `string` | Yes | `markdown`, `html`, or `rich_text` |
| `cover_assets` | `string[]` | No | Cover asset paths or URLs |
| `extra` | `object` | No | Platform-specific fields |
