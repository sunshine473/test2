## 协作规则

- 认领任务：在"负责人"列填写 `Claude` 或 `Codex`，状态改为 `进行中`
- 约束：状态为"进行中"时必须有负责人，不允许"待认领 + 进行中"的组合
- 完成后更新状态为 `Done`，"复盘"列写一句话结论，详细复盘写入 `docs/复盘记录.md`
- 如果任务有依赖关系，先完成前置任务再认领后续任务
- 遇到阻塞时在"备注"列写明原因（前缀 `BLOCKED:`），不要空等，可先做其他任务
- 完成任务后检查 `CLAUDE.md`、`README.md` 是否需要同步更新
