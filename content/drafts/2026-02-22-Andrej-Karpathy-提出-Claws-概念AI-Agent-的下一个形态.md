# Karpathy 新概念 “Claws”：AI Agent 之上，还有一层

AI Agent 火了一整年，从 AutoGPT 到 Claude Code，从 Cursor 到 Devin，大家都在聊怎么让 AI 自己干活。但你有没有想过一个问题：谁来管这些 Agent？

当你同时跑着一个帮你写代码的 Agent、一个帮你搜资料的 Agent、一个帮你处理邮件的 Agent——谁来协调它们？谁来记住上下文？谁来决定什么时候该干什么？

Andrej Karpathy 最近给出了他的答案：**Claws** 🦞。

不是让 Agent 变得更强，而是在 Agent 之上再加一层。就像 LLM Agent 是 LLM 之上的新层级一样，Claws 是 LLM Agent 之上的新层级。

这个概念一出，社区立刻炸了。NanoClaw、zeroclaw、ironclaw……一批开源项目迅速涌现，”Claw” 甚至已经成了这类系统的行业术语。

今天咱们就来拆解一下：Claws 到底是什么？它跟现有的 Agent 框架有什么本质区别？为什么 Karpathy 认为这才是 AI 的下一个形态？

## 1. AI Agent 的瓶颈：单兵作战的局限

先快速回顾一下现状。2025-2026 年，AI Agent 已经从概念走向了实用：Claude Code 能帮你写代码、Cursor 能帮你重构项目、各种 Agent 框架让 AI 能自主调用工具完成任务。

但用过的人都知道，当前的 Agent 有几个绕不开的痛点：

*   **没有持久记忆**：每次对话都是从零开始，上次帮你做的事它全忘了。你得反复交代背景。
*   **各自为战**：你可能同时用着写代码的 Agent、搜资料的 Agent、管日程的 Agent，但它们之间完全不通信，无法协作。
*   **缺乏调度能力**：Agent 只能响应你的即时指令，不能自己安排任务——比如”每天早上 8 点帮我看看有没有新的 PR 需要 review”。
*   **上下文碎片化**：你的工作上下文散落在不同的 Agent、不同的对话里，没有一个统一的地方来管理。

简单说：单个 Agent 已经很强了，但缺一个”管理层”来协调它们。这正是 Karpathy 提出 Claws 要解决的问题。

## 2. Claws 是什么？Agent 之上的编排层

Karpathy 的原话很精炼：

> “就像 LLM Agent 是 LLM 之上的新层级一样，Claws 现在是 LLM Agent 之上的新层级。”

这句话是理解 Claws 的关键。我们来拆解一下 AI 工具栈的三层架构：

```
Layer 3: Claws    → 编排调度、上下文管理、持久化、任务安排
Layer 2: Agent    → 工具调用、自主推理、任务执行
Layer 1: LLM      → 语言理解、文本生成、知识推理
```

**LLM** 是基础能力层——能理解语言、生成文本、做推理。
**Agent** 在 LLM 之上加了工具调用和自主决策——能搜索、写代码、操作文件。
**Claws** 在 Agent 之上再加一层——能协调多个 Agent、管理上下文、安排定时任务、持久化记忆。

打个比方：LLM 是一个聪明的员工，Agent 是一个能独立干活的项目经理，而 Claws 就是那个统管全局的 COO——它知道所有项目的进度，能调配资源，能安排日程，还能记住公司的所有历史决策。

Claws 系统的四大核心能力：

*   **编排与调度**：协调多个 Agent 协作完成复杂任务，决定谁先干、谁后干、谁并行
*   **上下文管理**：维护跨 Agent、跨会话的统一上下文，不再每次从零开始
*   **工具调用**：不仅自己能调用工具，还能把工具能力分配给下属 Agent
*   **持久化**：记住历史任务、用户偏好、项目状态，真正拥有”长期记忆”

更重要的是，Claws 通常运行在个人硬件上，通过消息协议与各个 Agent 通信。它既能响应你的直接指令（”帮我 review 这个 PR”），也能自主安排任务（”每天早上检查一下有没有新的 issue”）。

## 3. 生态爆发：4000 行代码的 AI 操作系统

Claws 不只是一个概念，社区已经在快速落地。Karpathy 特别提到了几个代表性项目：

**NanoClaw** 是目前最受关注的实现，核心引擎只有约 4000 行代码。Karpathy 对它的评价很有意思：”这个代码量既能装进我的脑子，也能装进 AI Agent 的脑子。”这句话点出了 Claws 设计哲学的核心——**可管理、可审计、足够灵活**。

除了 NanoClaw，还有 nanobot、zeroclaw、ironclaw、picoclaw 等一批开源项目在涌现。”Claw” 已经成了这类 OpenClaw 式 Agent 系统的行业术语，甚至有了专属 emoji 🦞。

这些项目的共同特征是：

*   **轻量级**：不是动辄几万行的重型框架，而是精简到可以被人类和 AI 同时理解的规模
*   **消息驱动**：通过标准化的消息协议（而非硬编码的函数调用）来协调 Agent
*   **本地优先**：运行在你自己的机器上，数据和上下文不离开本地
*   **可组合**：像乐高积木一样，可以灵活组合不同的 Agent 能力

这跟之前 LangChain、AutoGPT 那一波 Agent 框架有什么区别？最大的区别在于**抽象层级不同**。LangChain 解决的是”怎么让 LLM 调用工具”，而 Claws 解决的是”怎么让多个 Agent 协同工作并持久运行”。前者是 Agent 的内部实现，后者是 Agent 的外部编排。

## 4. 为什么 Claws 是下一个形态？

Claws 的出现不是偶然的，它解决的是 AI Agent 规模化应用的核心瓶颈。

### 4.1 从”一次性对话”到”持续运行的系统”

当前的 Agent 本质上还是”对话式”的——你说一句，它做一件事，做完就结束了。Claws 把 Agent 变成了一个持续运行的系统：它有记忆、有日程、有待办事项，能在后台默默工作。

这就像从”每次都要打电话叫外卖”变成了”有一个住家厨师，知道你的口味，到点就做饭”。

### 4.2 从”单兵作战”到”团队协作”

一个 Claws 系统可以同时编排多个 Agent：让代码 Agent 写代码、测试 Agent 跑测试、文档 Agent 更新文档，彼此之间通过消息协议通信，共享上下文。

这不是简单的”串行调用”，而是真正的并行协作——就像一个高效的开发团队。

### 4.3 从”云端依赖”到”本地自主”

Claws 强调运行在个人硬件上，这意味着：
*   你的数据和上下文不需要上传到云端
*   不依赖某个特定的 AI 服务商
*   可以离线工作，网络断了也不影响已有的上下文和任务安排

### 4.4 从”重型框架”到”可审计的轻量系统”

Karpathy 为什么特别推崇 NanoClaw 的 4000 行代码？因为这个规模意味着：
*   人类开发者可以完整理解整个系统
*   AI Agent 也可以理解并修改自己的编排层
*   出了问题可以快速定位和修复

这跟动辄几万行代码的 LangChain 形成了鲜明对比。Claws 的哲学是：编排层应该足够简单，复杂性留给被编排的 Agent。

## 5. 挑战与展望：Claws 的边界在哪？

Claws 的方向很清晰，但落地过程中有几个绕不开的问题。

### 安全与权限

当一个 Claws 系统能自主调度多个 Agent、安排定时任务、持久化运行时，权限管理就变得至关重要。它能访问哪些文件？能调用哪些 API？能不能自己给自己加权限？这些问题需要在架构层面解决，而不是靠 prompt 约束。

### 可观测性

系统越自动化，越需要让人类能看懂它在干什么。Claws 的编排逻辑、Agent 之间的消息流、任务执行历史，都需要清晰的日志和可视化。NanoClaw 的 4000 行代码之所以被推崇，正是因为它足够透明。

### 标准化

目前各个 Claw 项目各自为战，消息协议、Agent 接口、持久化格式都不统一。如果 Claws 要成为真正的行业标准，需要一套类似 OpenAPI 的规范来统一接口。OpenClaw 这个名字本身就暗示了这个方向。

### 与现有工具的融合

开发者已经在用 Claude Code、Cursor、各种 MCP Server。Claws 不应该要求大家推倒重来，而是应该能无缝编排这些已有的工具。谁能做好这个”胶水层”，谁就能赢得开发者。

## 总结：个人 AI 操作系统的雏形

回到最初的问题：Claws 到底是什么？

一句话总结：**Claws 是 AI Agent 之上的编排层，让多个 Agent 能协同工作、持久运行、自主调度。**

如果说 LLM 给了 AI “大脑”，Agent 给了 AI “手脚”，那 Claws 给的就是”神经系统”——把大脑和手脚连接起来，形成一个完整的、能自主运转的有机体。

Karpathy 看到的，不只是一个技术层级的演进，而是个人 AI 操作系统的雏形。想象一下：你的电脑上运行着一个 Claws 系统，它了解你的工作习惯、管理着你的各种 AI Agent、能自动安排日常任务、在你需要的时候主动提供帮助。

这不是科幻，NanoClaw 的 4000 行代码已经在朝这个方向走了。

AI 的进化从来不是线性的。从 GPT 到 Agent 是一次跃迁，从 Agent 到 Claws 可能是下一次。而这一次，Karpathy 又站在了浪尖上。
